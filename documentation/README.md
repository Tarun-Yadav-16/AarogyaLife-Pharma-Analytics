# Project Documentation

This folder contains the supporting documents for the AarogyaLife Pharma Business Analytics project.

## Files Included

### 1. Business Problem and Required Deliverables
**File:** `Business_Problem_and_Required_Deliverables.pdf`

Explains the business problem, project objectives, dataset scope, analysis requirements and expected deliverables.

### 2. Actual Findings
**File:** `Actual_Findings.md`

Contains the important findings generated from the analysis, including sales performance, profitability, payment collection, inventory risks and safety-reporting workload.

### 3. Business Case Presentation
**File:** `Business_Case_Presentation.pptx`

Provides a modern presentation of the complete project, including the business problem, analytical approach, dashboards, key insights, recommendations and business impact.

## Tools Used

- Python (Pandas) — data cleaning and transformation
- MySQL — data analysis and business queries
- Power BI — data modelling, DAX measures and dashboard development
